# 🕹️ Guessing Game

A simple command-line number guessing game written in Rust! 🎯

---

## 📦 Project Overview

This is a basic Rust project that helps you get familiar with:
- Taking user input
- Generating random numbers
- Control flow in Rust
- Error handling

---

## 🚀 How to Run

1. **Clone the repo:**

   ```bash
   git clone https://github.com/surenidh/rust.git
   cd rust/guessing_game
2. Build and run the game:
    cargo run
