# 📝 Rust CLI To-Do List

A simple command-line To-Do List application written in Rust.  
Perfect for learning Rust basics like structs, enums, `match`, user input, and the standard library.

## 📦 Features

- Add new to-do items
- View all tasks
- Mark tasks as completed
- Simple terminal UI
- Built with safe, efficient Rust code
